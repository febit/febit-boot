# 索引模板

> 只做 **导航**，不复述语义（复述即双写）。

## 阐述什么

| 问题           | 阐述                                      |
|----------------|-------------------------------------------|
| 这组文档答什么 | `## 定位` 一段                            |
| 哪篇答哪块     | 地图表：`文件` / 一句用途（不是内容摘要） |

## 禁令

- **语义定义** → 留在被索引的那一篇
- **状态 / 进度** → 不记载
- **实现细节** → 代码

## 参考结构

```markdown
## 定位
（这组文档解决什么问题）

| 文件 | 用途 |
|------|------|
| [xxx.md](xxx.md) | 一句用途 |
```
