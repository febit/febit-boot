# 模板索引

> `doc/**/*.md` 的模板来源；每个文件可复制，含 TODO 占位或参考结构。

> 本页是模板的 **唯一索引**；[AGENTS.md](../../AGENTS.md) 的「文档模板速查」镜像本页条目。
